# Authoritative Sources Used

## Singur Reservoir / Project
1. Telangana Irrigation & CAD Department — Mogaligundla Baga Reddy Singur Project project note
   https://irrigation.telangana.gov.in/img/projectspdf/singur.pdf
   Used for: location, river, gross capacity, FRL, 40,000-acre new ayacut, Singur-canal irrigation allocation, canal-head discharges and multipurpose context.

2. Central Water Commission — Sedimentation Assessment of Singur Reservoir through Remote Sensing
   https://cwc.gov.in/sites/default/files/sedimentation-assessment-singur-reservoir-through-srssep20_1.pdf
   Used for: designed gross/live capacity and remote-sensing assessed 2018 live capacity.

3. Central Water Commission — Guide to Prepare Chapter on Irrigation Planning Aspects of DPR
   https://www.cwc.gov.in/sites/default/files/guide-prepare-chapter-irrigation-planning-aspects-dpr-sepember-2018.pdf
   Used for: crop-water terminology, net/gross irrigation requirement concepts, project efficiency, reservoir working-table structure and 10-daily/monthly irrigation-planning practice.

## Weather and Crop-Water Methodology
4. NASA POWER Daily Point API
   https://power.larc.nasa.gov/
   Used for: daily meteorological variables for 2021–2025.

5. FAO Irrigation and Drainage Paper 56 — Crop Evapotranspiration
   https://www.fao.org/4/x0490e/x0490e00.htm
   Used for: Penman–Monteith ET0 framework and crop-coefficient methodology.

## Important source boundary
The project uses official Singur project characteristics to provide a real case-study context and scale check. It does not claim to have historical daily/10-daily Singur inflow, beginning-storage, drinking/industrial-release, evaporation or spill time series for the 2025 maize season. Those quantities are therefore not fabricated.

# CE4400 Irrigation Water Demand ML Project

The completed project is located in:

`Irrigation-Water-Demand-ML/`

It predicts daily grain-maize irrigation requirement from meteorological and crop-state variables and converts the prediction into reservoir-allocation units.

Final validation-selected model: XGBoost  
Final 2025 test: MAE 0.1349 mm/day, RMSE 0.2201 mm/day, R2 0.9804

See `Irrigation-Water-Demand-ML/README.md` for the complete methodology, results, repository structure and limitations.
